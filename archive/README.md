# Archive

Historical and deprecated project artifacts can be moved here after provenance is preserved in `experiments/registry.csv` or an external artifact manifest.

Archive policy:

- Prefer move/archive over deletion.
- Add a README or header explaining why each archived item is historical.
- State the canonical replacement path when one exists.
- Do not archive the only copy of raw experimental evidence unless it is also stored in a durable artifact store.

Canonical replacements created on 2026-08-17:

- Experiment lifecycle: `experiments/registry.csv`
- Canonical metrics: `results/canonical/*.csv`
- Human summary: `PROJECT_STATUS.md`
