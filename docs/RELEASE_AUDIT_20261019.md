## 术语

- **探针（probe）**：在冻结的基础模型特征上训练的轻量诊断模型，用来测量特征里含有什么空间信息。
- **checkpoint**：训练保存的模型权重文件。文件存在不等于训练正确。
- **Canonical V2**：采用第二版统一数据与特征协议的主线实验。
- **Timestep**：改变生成模型调度时间步取特征、比较表征的实验。时间步编号不代表噪声强弱，各模型坐标也不可直接对应。
- **A1/A2/B1/B2/C1/C2**：深度与实例身份、视角重叠、离开视野后的物体方向（B2 用外观查询）、单步动作预测、动作序列积分。
- **C3-from-C1**：不单独训练，在冻结的 C1 上，把同一锚点同一轨迹上 h1、h2、h4 三个终点当作三个候选动作，看预测是否更接近配对的目标。它是多动作敏感性诊断，不是反事实或因果结论。
- **旧版单独训练的 C3（legacy trained C3）**：历史上单独训练的 `counterfactual` 头，与 C3-from-C1 是不同实验，不能互相抵数。
- **冻结包**：训练时从主目录复制出的代码副本（集群 `runtime/<包名>`，被 git 忽略），训练与评估都在它上面运行。
- **stage 5**：用重新提取的 bf16 特征重训 MiniMax-H3 timestep 第 20/25 层的 128 个 run。
