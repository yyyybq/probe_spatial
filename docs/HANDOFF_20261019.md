## 项目在做什么

在冻结的视频 / 视觉基础模型特征上训练浅层诊断探针，看这些特征里能读出哪些空间信息。数据是 InsScene-15K 的 ScanNet++ 视频窗口（流式前缀）。Infinigen 不是视频轨迹，不能支撑时间或动作结论。

这不是在训练视频模型。流程是：提冻结特征 → 训轻量探针头 → 在 `val`、seed 42 上打分。

| 家族 | 探针 | 问题 |
| --- | --- | --- |
| A1 | `streaming_depth` / `streaming_mask` | 深度、相机、身份 |
| A2 | `view_consistency` | 视角重叠 |
| B1 / B2 | `ego_belief` / `ego_belief_v2` | 离开视野后的物体方向；B2 用外观 query |
| C1 | `action_dynamics` | 前缀特征 + 9 维相对相机动作，能否预测孤立的未来特征 |
| C2 | `path_integration` | 沿动作序列滚到后续路点 |
| C3 | 不单独训练 | 冻结的 C1 上做动作敏感性评估 |

C1 的绝对 `global_R@1` 不够。要和零动作、打乱动作、复制末帧对照一起看（`protocols/C_PROBES.md`）。
C3 用的是同一条轨迹上的 h1/h2/h4 终点，是多动作敏感性诊断，**不能写成反事实或因果**。
历史上单独训练的 C3 只作 `legacy_trained_c3`，不进现在的表。

模型包括 DINO、V-JEPA2、Fast3R、VideoMAE、Aether、CogVideoX、Wan、Qwen2.5-VL、MiniMax-H3、LingBot。
代码在 `vidfm3d/`、`features/`、`configs/`；协议在 `protocols/C_PROBES.md` 与 `EXPERIMENT_PROTOCOL.md`。
